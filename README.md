
# Student Management System

## About
A beginner-friendly Student Management System
developed using Python and Object-Oriented Programming.

## Features
- Add Student
- View All Students
- Search Student
- Delete Student
- Update Student Marks

## Concepts Used
- Python
- Classes and Objects
- Constructors
- Functions
- Lists
- Loops
- Conditional Statements

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

python main.py
